# 새롬 문법

구체적인 내용은 [예시](../examples/)를 참고해 주세요.

## 1. 소스

- UTF-8 / NFC
- `.sr` 확장자를 사용합니다.
- 공백 4칸 들여쓰기를 사용합니다.
- `#` 부터 줄 끝까지는 주석입니다.
- 문장은 `.` 이나 `:` 에서 끝납니다. 값 하나만 적은 표현문은 그 값에서
  끝납니다. 끝나지 않은 문장은 다음 줄로 이어집니다.

## 2. 토큰

### 2.1 낱말

| | |
|---|---|
| 수 | `0` `42` `3.14` `-5` |
| 문자열 | `"..."` `\n` `\t` `\\` `\"` `\{` `\}` |
| 논리값 | `참` `거짓` |
| 목록 | `[...]` `빈목록` |
| 기호 | `[` `]` `,` `:` `.` |

- `{ }` 로 문자열 보간을 사용할 수 있습니다.

- 이름에는 띄어쓰기를 사용할 수 없습니다.

> 예약어: `만약` `아니고` `아니면` `동안` `이런` `간격` `참` `거짓` `빈목록` `번째` `이유` `결과` `끝으로` `오류`

### 2.2 어절 나누기

한 어절(띄어쓰기와 기호로 끊긴 한 덩이)을 아래 차례대로 살펴 토큰으로 나눕니다.
앞선 규칙이 걸리면 거기서 멈춥니다.

1. 예약어와 부사는 그대로 하나의 토큰입니다.
2. **이미 선언된 이름은 나누지 않습니다.** 이 규칙이 없으면 `{나이}` 가
   `나` + `이` 로 갈라집니다.
3. 내장 용언의 활용형, 그리고 `하다` · `되다` 의 활용형으로 끝나는 어절은
   용언입니다. 사용자 동사는 반드시 `명사 + 하다` 꼴이라 표에 없어도
   생김새만으로 알아볼 수 있습니다.
4. `이다` 의 활용형으로 끝나면 거기서 자릅니다. 앞부분은 1번부터 다시 보되
   `이다` 를 또 떼지는 않습니다. `성인인` 이 `성` + `인` + `인` 으로 두 번
   갈라지지 않도록 하기 위해서입니다.
5. 어절 전체가 조사이거나 수로 읽히면 그대로 조사·수입니다.
6. 조사로 끝나면 조사를 **하나만** 뗍니다. 앞부분은 1번부터 다시 보되
   조사를 또 떼지는 않습니다.
7. 어느 것도 아니면 이름입니다.

- 2번의 "선언된 이름"은 소스를 한 번 훑어 모읍니다. 어딘가에서 조사가 붙은
  낱말과, `X들` 의 `X` 가 이름이 됩니다.
- 나누기는 앞뒤 문맥을 보지 않습니다. 같은 소스는 언제나 같게 나뉩니다.
  `이다` 의 준말 `다` `면` 을 받아들이지 않는 것도 이 때문입니다. 받아들이면
  `20보다` 가 `20보` + `이다` 로 갈릴 수 있습니다.

## 3. 조사

### 3.1 조사

| | |
|---|---|
| `은` `는` | 선언 |
| `이` `가` | 비교의 주어 |
| `을` `를` | 목적어 |
| `에` | 도착지, 덧셈·곱셈의 기준 |
| `에서` | 출처, 뺄셈의 기준 |
| `에게` | 수신자 |
| `로` `으로` | 수단, 나눗셈의 기준, 변환 결과 |
| `의` | 필드 접근, 모듈 이름공간 |
| `보다` | 비교 기준 |
| `만큼` | 수량 |
| `마다` | 반복 |
| `중` | 부분 선택 |
| `부터` `까지` | 범위 |
| `와` `과` | 접속 |

- `와`/`과` 로 이어진 낱말들은 하나의 목록으로 취급됩니다.
- `부터` `까지` 뒤에는 조사가 하나 더 붙을 수 있습니다: `까지의` `부터를`.

### 3.2 이형태

`은/는` 등의 이형태는 동일하게 취급됩니다. 어느 쪽을 적어도 뜻이 같습니다.

| 자리 | 받침 있음 | 받침 없음 |
|---|---|---|
| 선언 | `은` | `는` |
| 주어 | `이` | `가` |
| 목적어 | `을` | `를` |
| 수단 | `으로` | `로` |
| 접속 | `과` | `와` |

- `로`/`으로` 만 예외로, `ㄹ` 받침 뒤에는 `로` 를 씁니다.
- 수 뒤에서는 그 수를 읽은 소리로 고릅니다: `1은` `2는`.
- [포매터](tools.md#3-포매터)가 **이름 뒤에 바로 붙은** 조사만 바로잡습니다.
  문자열 뒤의 조사는 그 문자열을 소리 내어 읽어야 고를 수 있으므로 적은
  그대로 둡니다.

### 3.3 조사 자리

- 용언은 **이름과 조사 묶음**으로 가려집니다. 이름이 같아도 조사가 다르면
  다른 용언입니다.
- 조사가 서로 다르면 적는 차례는 상관없습니다. 같은 조사를 여러 번 쓰면
  적은 차례대로 매개변수에 묶입니다.
- 관형형 용언은 앞에 쌓인 구절 가운데 **뒤에서부터, 제 조사 묶음에 들어맞는
  가장 긴 만큼**을 가져갑니다. 나머지는 바깥 용언의 몫으로 남습니다.

  ```
  학생들에 줄들을 해석한 값을 더한다.
  ```

  `해석하다`는 `줄들을` 만 가져가고, `학생들에` 는 `더하다` 에게 남습니다.
- `중` `마다` `부터` `까지` `간격` 은 구성을 이루는 자리라 인자로 세지
  않습니다.

## 4. 어미

| | 하다 | 되다 | 이다 |
|---|---|---|---|
| 종결 | `한다` | `된다` | `이다` |
| 관형완료 | `한` | `된` | `인` |
| 관형현재 | `하는` | `되는` | `인` |
| 조건 | `하면` | `되면` | `이면` |
| 이음 (AND) | `하고` | `되고` | `이고` |
| 가름 (OR) | `하거나` | | `이거나` |
| 물음 | `하는지` | `되는지` | `인지` |
| 명사형 | `하기` | | |
| 부정 | `하지` + `않다` | | `아니다` |
| 보조 | `해` + `본다`/`둔다` | | |
| 인용 | | | `이라는` `라는` |

- 동사는 `명사 + 하다` 꼴로만 만들 수 있습니다.
- `아니다`는 `X가 Y가 아니다`의 꼴로 사용합니다.

## 5. 문장

| | |
|---|---|
| 선언문 | `<대상>는 <식>이다.` |
| 실행문 | `<구절>* <동사>ㄴ다.` — `-고` 로 잇는다 |
| 조건문 | `만약 <조건>면:` / `아니고 만약 <조건>면:` / `아니면:` |
| 반복문 | `<범위\|목록>마다 반복한다:` / `<조건>ㄴ 동안 반복한다:` |
| 중단문 | `빠져나간다.` |
| 계속문 | `넘어간다.` |
| 반환문 | `<식>을 돌려준다.` |
| 정의문 | `<구절>* <용언>ㄴ 것은:` |
| 구조체 선언 | `<이름>는 이런 것이다:` |
| 예외처리문 | `<구절>* <동사>어 본다:` / `해 본다:` |
| 자원문 | `<구절>* <동사>어 <이름>로 둔다:` |
| 예외발생문 | `<식>이라는 오류를 낸다.` |
| 가져오기문 | `<모듈>을 가져온다.` / `<모듈>에서 <이름>과 <이름>을 가져온다.` |
| 표현문 | `<식>` |

- `만약` 은 생략할 수 있습니다.
- 이어진 술어에서 주어가 없으면 앞의 주어를 물려받습니다.
- `<범위>`는 `<식>부터 <식>까지 (<식> 간격의)`의 꼴로 사용합니다.
- 정의문의 머리가 `<이름>ㄴ` 이면 술어이고, 술어는 `참`이나 `거짓`만 돌려줍니다.
- 반복문 안에서 `번째` 가 지금이 몇 번째인지를 담습니다. 반복문에 딸린
  이름이라 반복문을 벗어나면 없어지고, 안쪽 반복문이 바깥쪽 것을 덮어쓰지
  않습니다.
- 중단문과 계속문은 동사의 경계를 넘지 않습니다.

## 6. 목록

### 6.1 목록 다루기

`들`을 붙여 목록으로 사용할 수 있으며, `들`을 땐 이름으로 원소에 접근할 수 있습니다.

| | |
|---|---|
| `<관형절> A들` | 필터 |
| `A들 중 <관형절>인 것들` | 식에 대한 필터 |
| `A들을 각각 <용언>한 값들` | 맵 |
| `A들의 <필드>들` | 필드 맵 |
| `A들을 모두 <용언>한 값` | 리듀스 |
| `A들 중 가장 <술어>ㄴ 값` | 최대·최소 |
| `A들이 모두 <술어>ㄴ지` | 전체 판정 |
| `A들 중 하나라도 <술어>ㄴ지` | 존재 판정 |
| `<관형절> 순으로 정렬된 A들` | 정렬. `큰 순` 이 내림차순 |
| `A들마다 반복한다:` | 순회 |

- 빈 목록의 최대·최소는 오류입니다. 고를 원소가 없기 때문입니다.
- 빈 목록의 리듀스는 그 용언의 항등원을 냅니다. `더하다` 는 `0`, `곱하다` 는
  `1`, `잇다` 는 `""` 입니다. 항등원이 정해지지 않은 용언이면 오류입니다.

### 6.2 부사

`모두` `각각` `가장` `하나라도` 는 용언이 목록에 어떻게 걸리는지를 고릅니다.
용언 이름의 일부가 아니라서 용언과 떨어져 놓일 수 있습니다.

```
숫자들을 각각 2로 나눈 값들
```

## 7. 구조체

```
<이름>는 이런 것이다:
    <필드>는 <자료형>이다.
```

## 8. 능동과 피동

능동의 `을`/`를` 자리는 피동에서 `이`/`가` 가 되고, 그 다음에 오는 명사가 첫 매개변수 자리에 들어갑니다.

- 능동은 대상을 그 자리에서 바꾸고, 피동은 대상을 복사한 뒤 그 복사본을
  냅니다. `수들을 정렬한다` 는 `수들` 자체를 줄 세우고,
  `정렬된 수들` 은 `수들` 을 그대로 둔 채 줄 세운 새 목록을 냅니다.
- 피동형은 `명사 + 하다` 동사에만 있습니다 (`정렬하다` → `정렬되다`).
  `더하다` `빼다` 처럼 `하다` 로 만들어지지 않은 내장 동사에는 피동형이
  없습니다.

## 9. 모듈

- `<모듈>.sr` 이나 `<모듈>.py` 를 찾습니다.
- 같은 디렉터리에서 먼저 시도하고 그다음 표준 라이브러리를 시도합니다.
- 순환참조를 지원하지 않습니다.
- 모듈 이름을 그대로 가져오면 `<모듈>의` 를 붙여 씁니다.

## 10. 내장

### 10.1 내장 용언

| |  |
|---|---|
| `~에 ~를 더한다` | `+`. `~에` 자리가 목록이면 뒤에 붙인다 (원본이 바뀐다) |
| `~에서 ~를 뺀다` | `-` |
| `~에 ~를 곱한다` | `*` |
| `~를 ~로 나눈다` | `/`. `~ 나눈 나머지` 가 `%` |
| `~가 ~보다 크다` | `>` |
| `~가 ~보다 작다` | `<` |
| `~가 ~와 같다` | `==` |
| `~를 출력한다` | `print` |
| `입력받는다` | `input` |
| `~를 연다` | `open` |
| `~를 읽는다` | `read` |
| `~에 ~를 쓴다` | `write` |
| `~를 ~로 바꾼다` | `int` `float` `str` `bool` |
| `~를 정렬한다` / `~를 ~로 정렬한다` | `sorted` |
| `~를 ~로 자른다` | `str.split` |
| `~를 잇는다` / `~를 ~로 잇는다` | `str.join` |
| `~가 ~를 담는다` | `in` |
| `~가 ~로 시작한다` | `startswith` |
| `~가 ~로 끝난다` | `endswith` |
| `~를 다듬는다` | `strip` |
| `~를 가져온다` | `import` |

- 나눗셈은 딱 떨어지면 정수를, 아니면 실수를 냅니다.
- `~를 정렬한다` 는 목록을 그 자리에서 줄 세우고 아무 값도 내지 않습니다.
  줄 세운 새 목록이 필요하면 피동형 `정렬된 ~` 을 씁니다 (8).

### 10.2 내장 필드

`의` 로 읽습니다.

| 대상 | 필드 |
|---|---|
| 아무 값 | `자료형` |
| 목록 | `개수` `길이` `마지막` |
| 문자열 | `글자수` `길이` `개수` `마지막` |
| 목록·문자열 | `첫째` `둘째` … `열째`, `<수>번째`, `<이름>번째` |
| 목록 | `<필드>들` — 원소마다 그 필드를 모은 목록 |
| 구조체 | 선언한 필드 |
| 모듈 | 그 모듈의 값 |

- `자료형` 은 `정수` `실수` `문자열` `논리값` `목록` 이나 구조체의 이름을 냅니다.
- 자리를 벗어난 `첫째` `<수>번째` 는 값 오류입니다.
