# 새롬 문법

구체적인 내용은 [예시](../examples/)를 참고해 주세요.

## 소스

- UTF-8 / NFC
- `.sr` 확장자를 사용합니다.
- 공백 4칸 들여쓰기를 사용합니다.

## 토큰

| | |
|---|---|
| 수 | `0` `42` `3.14` `-5` |
| 문자열 | `"..."` `\n` `\t` `\\` `\"` `\{` |
| 논리값 | `참` `거짓` |
| 목록 | `[...]` `빈목록` |
| 기호 | `[` `]` `,` `:` `.` |

- `{ }` 로 문자열 보간을 사용할 수 있습니다.

- 이름에는 띄어쓰기를 사용할 수 없습니다.

> 예약어: `만약` `아니고` `아니면` `동안` `이런` `간격` `참` `거짓` `빈목록` `번째` `이유` `결과` `끝으로` `오류`

## 조사

| | |
|---|---|
| `은` `는` | 선언 |
| `이` `가` | 비교의 주어 |
| `을` `를` | 목적어 |
| `에` | 도착지, 덧셈·곱셈의 기준 |
| `에서` | 출처, 뺄셈의 기준 |
| `에게` | 수신자 |
| `로` `으로` | 수단, 나눗셈의 기준, 변환 결과 |
| `의` | 필드 접근, 모듈 이름공간 |
| `보다` | 비교 기준 |
| `만큼` | 수량 |
| `마다` | 반복 |
| `중` | 부분 선택 |
| `부터` `까지` | 범위 |
| `와` `과` | 접속 |

- `은/는` 등의 이형태는 동일하게 취급됩니다.
- `와`/`과` 로 이어진 낱말들은 하나의 목록으로 취급됩니다.

## 어미

| | 하다 | 되다 | 이다 |
|---|---|---|---|
| 종결 | `한다` | `된다` | `이다` |
| 관형완료 | `한` | `된` | `인` |
| 관형현재 | `하는` | `되는` | `인` |
| 조건 | `하면` | `되면` | `이면` |
| 이음 (AND) | `하고` | `되고` | `이고` |
| 가름 (OR) | `하거나` | | `이거나` |
| 물음 | `하는지` | `되는지` | `인지` |
| 명사형 | `하기` | | |
| 부정 | `하지` + `않다` | | `아니다` |
| 보조 | `해` + `본다`/`둔다` | | |
| 인용 | | | `이라는` `라는` |

- 동사는 `명사 + 하다` 꼴로만 만들 수 있습니다.
- `아니다`는 `X가 Y가 아니다`의 꼴로 사용합니다.

## 문장

| | |
|---|---|
| 선언문 | `<대상>는 <식>이다.` |
| 실행문 | `<구절>* <동사>ㄴ다.` — `-고` 로 잇는다 |
| 조건문 | `만약 <조건>면:` / `아니고 만약 <조건>면:` / `아니면:` |
| 반복문 | `<범위\|목록>마다 반복한다:` / `<조건>ㄴ 동안 반복한다:` |
| 중단문 | `빠져나간다.` |
| 계속문 | `넘어간다.` |
| 반환문 | `<식>을 돌려준다.` |
| 정의문 | `<구절>* <용언>ㄴ 것은:` |
| 구조체 선언 | `<이름>는 이런 것이다:` |
| 예외처리문 | `<구절>* <동사>어 본다:` / `해 본다:` |
| 자원문 | `<구절>* <동사>어 <이름>로 둔다:` |
| 예외발생문 | `<식>이라는 오류를 낸다.` |
| 가져오기문 | `<모듈>을 가져온다.` / `<모듈>에서 <이름>과 <이름>을 가져온다.` |
| 표현문 | `<식>` |

- `만약` 은 생략할 수 있습니다.
- 이어진 술어에서 주어가 없으면 앞의 주어를 물려받습니다.
- `<범위>`는 `<식>부터 <식>까지 (<식> 간격의)`의 꼴로 사용합니다.
- 정의문의 머리가 `<이름>ㄴ` 이면 술어이고, 술어는 `참`이나 `거짓`만 돌려줍니다.

## 목록

`들`을 붙여 목록으로 사용할 수 있으며, `들`을 땐 이름으로 원소에 접근할 수 있습니다.

| | |
|---|---|
| `<관형절> A들` | 필터 |
| `A들 중 <관형절>인 것들` | 식에 대한 필터 |
| `A들을 각각 <용언>한 값들` | 맵 |
| `A들의 <필드>들` | 필드 맵 |
| `A들을 모두 <용언>한 값` | 리듀스 |
| `A들 중 가장 <술어>ㄴ 값` | 최대·최소 |
| `A들이 모두 <술어>ㄴ지` | 전체 판정 |
| `A들 중 하나라도 <술어>ㄴ지` | 존재 판정 |
| `<관형절> 순으로 정렬된 A들` | 정렬. `큰 순` 이 내림차순 |
| `A들마다 반복한다:` | 순회 |

## 구조체

```
<이름>는 이런 것이다:
    <필드>는 <자료형>이다.
```

## 능동과 피동

능동의 `을`/`를` 자리는 피동에서 `이`/`가` 가 되고, 그 다음에 오는 명사가 첫 매개변수 자리에 들어갑니다.

## 모듈

- `<모듈>.sr` 이나 `<모듈>.py` 를 찾습니다.
- 같은 디렉터리에서 먼저 시도하고 그다음 표준 라이브러리를 시도합니다.
- 순환참조를 지원하지 않습니다.
- 모듈 이름을 그대로 가져오면 `<모듈>의` 를 붙여 씁니다.
