# 새롬 문법

구체적인 예는 [예시](../examples/)를 참고해 주세요.

## 소스

UTF-8 / NFC, 확장자 `.sr`, 공백 4칸 들여쓰기.

## 토큰

| | |
|---|---|
| 수 | `0` `42` `3.14` `-5` |
| 문자열 | `"..."` — `{ }` 는 보간, `\{` 는 중괄호 |
| 논리값 | `참` `거짓` |
| 목록 | `[...]` |
| 사전 | `{}` `{<이름>: <식>, ...}` |

- 이름에는 띄어쓰기를 사용할 수 없습니다.
- 조사, 예약어, 활용형과 같은 이름을 사용할 수 없습니다.

> 예약어: `만약` `아니고` `아니면` `동안` `간격` `참` `거짓` `끝으로` `오류`

## 조사

| | |
|---|---|
| `은` `는` `이` `가` | 선언, 주어 |
| `을` `를` | 목적어 |
| `에` | 도착지, 덧셈·곱셈 |
| `에서` | 출처, 뺄셈 |
| `에게` | 수신자 |
| `로` `으로` | 수단, 나눗셈, 변환 |
| `의` | 필드, 이름공간 |
| `보다` | 비교 기준 |
| `만큼` | 수량 |
| `마다` | 반복 |
| `부터` `까지` | 범위 |
| `와` `과` | 접속 |

- 구절의 순서는 자유입니다.
- 한 정의에서 같은 조사는 한 번만 쓸 수 있습니다.
- `은/는` 등의 이형태는 동일하게 취급됩니다.
- `와`/`과` 로 이어진 낱말들은 하나의 목록으로 취급됩니다.

## 어미

| | 어간 (`뒤집다`) | 하다 | 되다 | 이다 |
|---|---|---|---|---|
| 종결 | `뒤집는다` | `한다` | `된다` | `이다` |
| 관형완료 | `뒤집은` | `한` | `된` | `인` |
| 관형현재 | `뒤집는` | `하는` | `되는` | `인` |
| 조건 | `뒤집으면` | `하면` | `되면` | `이면` |
| 이음 (AND) | `뒤집고` | `하고` | `되고` | `이고` |
| 가름 (OR) | `뒤집거나` | `하거나` | | `이거나` |
| 물음 | `뒤집는지` | `하는지` | `되는지` | `인지` |
| 부정 | `뒤집지` + `않다` | `하지` + `않다` | | `아니다` |
| 보조 | `뒤집어` + `본다`/`둔다` | `해` + `본다`/`둔다` | | |
| 인용 | | | | `이라는` `라는` |

- 동사는 `명사 + 하다` 나 고유어 어간, 피동은 `명사 + 되다`, 술어는 `명사 + 이다` 꼴로 만듭니다.
- 사전형으로 정의합니다. (예: `글을 뒤집다라는 것은:` -> `뒤집다`)
- 규칙 활용과 ㄹ탈락을 지원합니다. (`만들다` -> `만든다` `만든` `만드는` `만들면`)
- 활용형이 선언된 이름과 같으면 선언된 이름이 우선합니다.
- `아니다` 는 `X가 Y가 아니다` 꼴로 씁니다.
- 물음꼴(`~ㄴ지`)로 부른 결과는 `참`이나 `거짓`이어야 합니다.

## 문장

| | |
|---|---|
| 선언문 | `<대상>는 <식>이다.` / `<대상>가 <식>이다.` |
| 실행문 | `<구절>* <동사>ㄴ다.` — `-고` 로 잇는다 |
| 조건문 | `만약 <조건>면:` / `아니고 만약 <조건>면:` / `아니면:` |
| 반복문 | `<범위>의 <이름>마다 반복한다:` / `<조건>ㄴ 동안 반복한다:` |
| 중단문 | `빠져나간다.` |
| 계속문 | `넘어간다.` |
| 반환문 | `<식>을 돌려준다.` |
| 정의문 | `<구절>* <머리>(이)라는 것은:` |
| 예외처리문 | `해 본다:` — `(<이름>으로) 실패하면:` / `끝으로:` 가 뒤따른다 |
| 자원문 | `<구절>* <동사>어 <이름>로 둔다:` |
| 예외발생문 | `<식>이라는 오류를 낸다.` |
| 가져오기문 | `<모듈>을 가져온다.` / `<모듈>에서 <이름>과 <이름>을 가져온다.` |
| 표현문 | `<식>` |

- `만약` 은 생략할 수 있습니다.
- 이어진 술어에서 주어가 없으면 앞의 주어가 사용됩니다.
- `<범위>` 는 `<식>부터 <식>까지 (<식> 간격)` 꼴입니다.
- 반복문의 `마다` 앞은 반복 변수의 이름입니다. 범위가 없으면 구문 오류입니다.

## 목록

| | |
|---|---|
| `A의 첫째` ~ `열째`, `마지막`, `<수>번째` | 자리 |
| `A의 개수` | 원소의 수 |
| `A에 <값>을 더한다` | 뒤에 붙이기 |

- `<수>번째` 의 수 자리에는 정수를 담은 이름도 쓸 수 있습니다.
- 원소를 하나씩 보려면 자리를 셉니다. (`1부터 A의 개수까지의 자리마다 반복한다:`)
- 문자열의 글자수는 `<글>의 글자수` 입니다.

## 사전

```
<이름>는 {}이다.
<이름>는 {<열쇠>: <식>, <열쇠>: <식>}이다.
```

- 열쇠는 이름 하나입니다. 문자열이나 식은 열쇠가 될 수 없습니다.
- 읽기와 쓰기는 `<사전>의 <열쇠>` 로 합니다. 없는 열쇠에 매기면 새로 생깁니다.
- 없는 열쇠를 읽으면 이름 오류입니다.

## 파생 필드

```
<소유자>의 <이름>(이)라는 것은:
```

- `<소유자>의 <이름>` 으로 씁니다.
- 반드시 값을 반환해야 합니다.
- 사전의 열쇠와 목록·문자열의 필드가 파생 필드에 우선합니다.
- 다른 모듈의 파생 필드는 `<모듈>의 <이름>`의 꼴로 사용할 수 없습니다.

## 모듈

- `<모듈>.sr` 이나 `<모듈>.py` 를 찾습니다. 같은 디렉터리가 표준 라이브러리에 우선합니다.
- 순환참조를 지원하지 않습니다.

| `~가 ~보다 크다` / `작다` | `>` `<` |
| `~가 ~와 같다` | `==` |
| `~가 ~ 이상/이하/초과/미만이다` | `>=` `<=` `>` `<` |
| `~를 출력한다` | `print` |
| `입력받는다` | `input` |
| `~를 연다` | `open` |

| `~에 ~를 쓴다` | `write` |
