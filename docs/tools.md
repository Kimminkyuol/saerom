# 새롬 도구

## 1. 실행기

### 1.1 종료 코드

| 코드 | 뜻 |
|---|---|
| 0 | 성공 |
| 1 | 프로그램 오류, 파일 없음, 형식 어긋남 |
| 2 | 인자가 맞지 않음 |
| 70 | 실행기 내부 오류 |
| 130 | 중단 (Ctrl-C) |

### 1.2 환경 변수

| 변수 | 뜻 |
|---|---|
| `SAEROM_DEBUG=1` | 파이썬 추적을 함께 출력 |
| `NO_COLOR` | 오류 출력에 색을 쓰지 않음 |

---

## 2. 오류

### 2.1 형식

```
역추적 (가장 최근 호출이 마지막):
  파일 "성적.sr", 9번째 줄, <맨바깥>
    "{철수의 평균점수}"를 출력한다.
  파일 "성적.sr", 6번째 줄, 평균점수 안
    학생의 점수를 모두 더한 값을 돌려준다.
           ^^^^
이름 오류: 구조체 '학생'에 필드 '점수' 없음
           필드: 이름, 점수들
```

### 2.2 갈래

| 갈래 | 언제 |
|---|---|
| 어휘 오류 | 따옴표 미종료, 들여쓰기 어긋남, 쓸 수 없는 글자 |
| 구문 오류 | 문법에 맞지 않음 |
| 이름 오류 | 정의되지 않은 이름·용언·필드 |
| 조사 오류 | 용언을 맞지 않는 조사로 호출 |
| 값 오류 | 자료형이 맞지 않음 |
| 산술 오류 | 0으로 나눔 |
| 재귀 오류 | 재귀가 200단계를 넘음 |
| 예외 | `~라는 오류를 낸다` 로 발생 |
| 실행 오류 | 위에 들지 않는 실행 중 오류 |

### 2.3 예외의 이유

| 이유 | 언제 |
|---|---|
| `파일없음` | `읽다` `열다` 가 파일을 찾지 못함 |
| `권한없음` | `읽다` 가 파일을 열 권한이 없음 |
| `입력끝` | `입력받다` 가 읽을 줄이 더 없음 |

## 3. 포매터

```
saerom --format <파일>...   덮어쓰기
saerom --check  <파일>...   확인하기
```

조사의 이형태와 간격, 들여쓰기를 고칩니다. 문자열 뒤의 조사는 그대로 둡니다.

---

## 4. 파이썬 모듈

```python
from saerom.extension import fail, noun, verb

VALUES = {"하루초": 86400}


@verb("나누기하다", "를", "로")
def divide(left, right):
    if right == 0:
        fail("0으로 나눌 수 없음")
    return left / right


@noun("절반")
def half(number):
    return number / 2
```

| | |
|---|---|
| `@verb(<이름>, <조사>...)` | 동사. 이름이 `하다`나 `되다`로 끝남 |
| `@predicate(<이름>, <조사>...)` | 술어. 이름이 `이다`로 끝나고 참/거짓만 냄 |
| `@noun(<이름>)` | 파생 필드. 소유자 하나를 받음 |
| `VALUES` | 이름과 값의 사전 |
| `fail(<이유>)` | 오류를 냄. `<이유>으로 실패하면:` 이 받음 |
